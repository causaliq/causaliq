# 🔍 CausalIQ Discovery

CausalIQ Discovery provides advanced algorithms for learning causal structures from data and human & LLM-derived knowledge.

**Quick Links:**

 - [📖 Full Documentation](https://causaliq.github.io/causaliq-discovery/)
 - [💻 Repository](https://github.com/causaliq/causaliq-discovery)
 - 🚀 Quick Start - coming soon

## 🚀 Proposed Features

- score-based **HC** and **Tabu** algorithms
- Support for **discrete and continuous** data types
- **Stability enhancements** so that results not dependent on arbitrary artifacts of the data (e.g. variable order)
- **Active learning** whereby algorithm can dynamically request knowledge in areas of uncertainty.

## Integration with Ecosystem

- 🎯 **CausalIQ Data** is used by this package to determine the score of graphs.
- 🧠 **CausalIQ Knowledge** is used by this package to supply human and LLM-derived knowledge.
- 🤖 **CausalIQ Workflow** uses this package in structure learning workflows.

## Standalone Use

Users may use this package standalone in one-off structure learning experiments, as part of their own workflows, or
as steps within [CausalIQ Workflows](workflow.md)
